# V0.46 Counterexample audit (pilot)

Uses unchanged V0.45 browser search cores, extracted from index.html. No UI changes. Node 22; no external packages.

```sh
node research/v46/audit.cjs > research/v46/results.json
node research/v46/audit.test.cjs
```

6 calibration laws, 6 distinct held-out synthetic laws, one seed per law, combined covariate/noise shift. 240 initial + 96 additional fits per task, shared model across methods. Each active method queries 12 unique points of 289; common noisy observation ledger. Fixed hybrid weights 0.25 disagreement, 0.45 train-distance novelty, 0.30 coverage. Calibration threshold is 4th smallest of 6 scores; test outcomes are not used to select thresholds.

Pilot only: larger runs timed out, no external benchmark, time matching, online correction or browser integration.
