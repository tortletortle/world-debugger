# WORLD.DEBUG / 世界调试器

一个以世界规则编辑、因果调试与科学规律发现为核心的浏览器项目。

## 运行
直接使用现代浏览器打开 `index.html`（V0.45）。无需安装依赖。V0.44 快照位于 `versions/`。

## 复现 V0.45（待迁入独立研究文件）
使用 Node.js 22（无 npm 依赖）：

```sh
node research/v45/world-debug-v45-benchmark.cjs
```

脚本会重新生成 JSON 实验数据与源宏记忆。目标任务 6 种合成规律 × 3 种偏移 × 3 个种子，共 54 组；共享初始搜索 240 次拟合，每种策略追加 96 次拟合。训练源记忆 2360 次拟合，协议总计 41240 次（不含断言复查）。

| 方法 | 无噪测试 RMSE | 负迁移（相对任务内组合 >10%） | 严重失败（RMSE >2） |
|---|---:|---:|---:|
| 自主组合 | 2.0379 | 0 | 12 |
| 历史排序 | 1.9834 | 11 | 12 |
| 残差检索 | 2.1057 | 13 | 12 |
| 固定混合 | 1.8046 | 7 | 12 |
| 自适应预算 | 1.9602 | 8 | 12 |

各策略模型拟合次数、动态特征生成数量相同，混合方法每组筛选 3120 次，其他方法 1848 次；残差检索另有检索成本。运行时间受并行任务和硬件影响，不能当作严格等计算预算实验。无真实数据或外部算法对照；目标规律是源任务之外的人工组合，不代表独立第三方基准。严重失败未减少。浏览器实验室已验证运行、停止、导出、回放和移动布局，未完整回归历史游戏关卡。
