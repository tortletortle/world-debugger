# WORLD.DEBUG / 世界调试器

一个以世界规则编辑、因果调试与科学规律发现为核心的离线浏览器实验室。重点是让世界规则可观察、可推演、可干预，并通过独立证据决定模型在什么状态区域内可以使用。

## 当前版本：V0.55

直接打开 [V0.55 交互演示](demo/v55/index.html)，无需安装依赖。

V0.55 修复 V0.54 的旧模型授权失效问题：残差报警后立即撤销当前模型权限，重新训练和审计期间使用名义模型；只有审计通过才授予新的授权代次。界面显示授权状态、代次、撤销次数及最近撤销原因。

## 研究边界

当前证据来自合成三圆盘动力学，不等于真实物理世界验证。残差报警阈值仍是未校准的工程阈值；授权范围外的样本尚未进入独立 shadow monitor；覆盖包络不是置信区间，也不提供安全保证。外部基准与真实浏览器验收仍待完成。
