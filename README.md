# WORLD.DEBUG / 世界调试器

一个以世界规则编辑、因果调试与科学规律发现为核心的离线浏览器实验室。重点是让世界规则可观察、可推演、可干预，并通过独立证据决定模型在什么状态区域内可以使用。

## 当前候选：V0.56
直接打开 [V0.56 交互演示](demo/v56/index.html)，无需安装依赖。

V0.56 在 V0.55 的可撤销授权机制上增加授权区域外的只读影子监测：使用按区域独立维护的能量 CUSUM 识别未授权区域中的持续模型失配。影子报警只生成候选证据，不改变当前控制器或授权。

## 研究边界
证据来自合成三圆盘动力学。能量 CUSUM 参数未校准，x 符号二分区较粗，未验证真实物理环境。影子报警不等于因果证明或模型授权；覆盖包络不是置信区间，也不提供安全保证。
